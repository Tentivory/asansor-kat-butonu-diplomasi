# ASANSÖR KAT BUTONU DİPLOMASİSİ

> Resmi statü: Ciddiyeti şaka olan, şakası ciddiye alınan kamu hizmeti.

Bu depo, iki yabancının aynı asansörde karşı karşıya kaldığında ortaya çıkan uluslararası krizi çözer. Sorun teknik değildir. Sorun, kapı kapanmadan önce birinin 4'e basmış olması, diğerinin de 4'e basmak istemesi ama butonun zaten yanmasıdır. Bu anda evren durur.

## Neden var?

Çünkü birisi "ben basayım mı" dedi, diğeri "basılı zaten" dedi, sonra ikisi de 11 saniye tavana baktı. Bu olayı protokole bağlamadan bırakmak sorumsuzluktur.

## Kurulum

Python 3 yeter. Bağımlılık yok. Asansör şart değil, utangaçlık şart.

```bash
python3 protokol.py
```

İstersen argüman da ver:

```bash
python3 protokol.py --kat 7 --yolcu 3 --goz-temasi evet
```

## Ne yapar?

- Kat butonunun zaten yanıp yanmadığını resmen tespit eder.
- Göz temasını ihlal sayar.
- "Ben basayım mı" cümlesine diplomatik nota keser.
- Utanç puanı üretir. 100 üstü kriz, 40 altı medeni sessizliktir.
- Raporu Türk bürokrasisi formatında basar. Kaşe yerine `DAMGA` vardır.

## Copilot notu

Bu depoda Copilot'a `.github/copilot-instructions.md` bırakıldı. Copilot'tan rica, asansörde sohbet açmasın. Açarsa protokol bozulur.

## Lisans

Butona bir kere basıldıysa ikinci basış manevi tazminat doğurur. Ayrıntı `LISANS.txt` içinde.

## Gizli dosya

`protokol/ic-tutanak.b64` iç işleri tutanağıdır. Açmak zorunda değilsin. Açarsan da "ben bunu okumadım" diyebilirsin, protokol buna izin verir.
